# AI Resume ATS Analyzer

An AI-powered Resume ATS Analyzer built using Python, Streamlit, NLP, and Machine Learning.

## Features

- Upload multiple resumes in PDF format
- Compare resumes with Job Descriptions
- Calculate ATS scores
- Extract technical skills automatically
- Identify missing skills
- Rank candidates based on ATS score
- Interactive analytics dashboard
- Generate downloadable reports

## Tech Stack

- Python
- Streamlit
- NLP
- Scikit-learn
- Plotly
- PyPDF2
- Pandas

## Installation

```bash
git clone https://github.com/shrutisharma26/Resume-ATS-Analyzer.git
cd Resume-ATS-Analyzer

pip install -r requirements.txt

streamlit run app/streamlit_app.py
```
